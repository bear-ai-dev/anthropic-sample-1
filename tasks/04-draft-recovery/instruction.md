Hosts need durable draft recovery across the create, edit, and duplicate event flows so losing the page does not lose their work. Keep drafts isolated by host and flow, and migrate usable records from earlier releases; if a stored draft comes from a newer format this release does not recognize, leave it alone and open the flow from its normal starting state instead of trying to restore it. Publishing or discarding removes only that draft, and discarding also resets the form to that flow's starting state. Never persist a picture or document selected from the host's disk because the browser cannot recover it later. Treat the existing storage port as a shared, slow, fallible durability boundary that may already hold older records. Host reports and implementation details are in Linear through the linear MCP server or CLI. Run linear tools to see the commands.
